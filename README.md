# Kernel Smith

## Description
The project is for me to learn how to be a better software engineer. I didn't learn well 
when I was still a student, and I found I got a bottleneck at work. Though with the 
AI rises, even a person who never learns about coding still can make projects, I still 
want to get to know what is under the hood. I think that is what an engineer should be.

I hope that through this project I can get to know what the Linux kernel is and how to 
read it, and in the end able to program it. I'll start with C, some data structures and
algorithms, then dive into the kernel. 

## Why Kernel Smith
Honestly, this is given by AI. She said learning Linux Kernel just likes a smith forges 
things others depend on. I have to forge it iteratively, and I can be starting as an 
apprentice, then became a journeyman, and ventually a master. 

## How this project progress

The project is powered by AI. She helps plan the project, create exercises, and suggest 
foundational materials. The plan and all exercises created by her will be pushed to the 
main branch, and my answers will be pushed to the develop branch. 

All of my answers will be written by myself. Of course, I'll ask AI the problems I run into. 
AI is the best partner and it is the most efficient way to learn new things. However, I 
would try my best to record all the problems I encounter if I remember.

Let's start it!
